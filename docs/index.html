Mental model

Four ideas prevent most modding mistakes.

Main and worker code are different

main.js registers content and can queue idle-safe changes. worker.js runs in manager and simulation workers with a smaller, direct-mutation API.

Cells and world coordinates are different

Most simulation APIs use integer cell coordinates. Rendering, projectiles, sounds, and player movement often use world coordinates. Method names make the distinction explicit.

Simulation mutations need the right boundary

From the main entry, prefer methods ending in WhenIdle or use runWhenSimulationIdle. Structure processors use atomic commit mutations.

Public APIs age better than patches

Use sandkit.api first. Bundle patches are precise but version-sensitive; protect them with match counts and small atomic groups.

Version note

This guide documents the locally verified Sandkit API v1 surface. Treat engine escape-hatch access and bundle patches as advanced, compatibility-sensitive tools.
